在 iPhone Safari 開啟

  1. 把這個 HTML 檔放進一個靜態網站託管服務（例如 GitHub Pages）。
  2. 部署後用 iPhone Safari 開啟該網址，再點語音的「試聽」。
  3. iOS Safari 只會列出它實際回報給網頁的語音；設定中新增的語音不一定會出現在清單。按「重新整理」後若仍沒有 es-ES，代表 Safari 目前沒有提供這種語音。

直接在電腦預覽無法確認 iPhone 實際提供哪些聲音。瀏覽器只會列出它回報的語音；若 iOS Safari 沒有提供 es-ES，本頁不會改用其他語言冒充。
